Trust

Why you can trust the download

You don't have to take our word for it: the code is public and every download can be checked.

  • 📖 Public codeWhat it reads, what it sends, where your keys go. Read it on GitHub
  • 🏗️ Built in publicEach download is built by GitHub Actions from a tagged commit, not on anyone's laptop. The build logs are public.
  • ✅ CheckableGitHub signs each download with the commit it was built from. With the GitHub CLI: gh attestation verify Job-Pilotto-mac-arm64.dmg -R GarryOne/job-pilotto
  • 🔒 Nothing about you on our serversWith Free AI, a request passes through our server to the model and nothing is stored; with your own key, the AI runs from your computer. We only receive scrubbed technical reports, and you can turn them off.
  • ✋ You submitIt fills forms and never presses Submit or applies in bulk.
  • ⚠️ Not signed by Apple or Microsoft yetThat's why your computer asks once before opening it. Found a problem? Report it privately
