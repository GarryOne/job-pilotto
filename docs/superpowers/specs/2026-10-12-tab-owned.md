# Every tab owned by its session from the moment it opens (12 Oct 2026)

> **Verdict:** a session's tab carries its session **in its own address** (`#jobpilotto-fill=<session id>`), so it is owned at first sight, survives a
> Chrome restart, and is never guessed. **One function** picks a session's tab for every use; guessing stays only for pre-change tabs and never opens a tab.
> Status: **design approved in principle by the owner (12 Oct 2026); this spec awaits the OK in the session window before any code.**

| Key numbers | |
|---|---|
| Today | tab gets its session late (job address → `resolveSession` → `bindSession`); until then `scoreTab` guesses |
| After | session known at open (address mark or `chrome.tabs.create` id); guess only for unowned legacy tabs |
| Places that pick a tab today | 6 (`openFormTab`, `withOpenForm`, `reloadTarget`/close/reload, `focusTabById`, `focusTabAt`, `review` state `tab`) → 1 |
| PRs | 3, each with its proof |

## Why (owner, 12 Oct 2026: "we fixed this bug thousands of times")
Wrong tab focused, an empty new tab opened, "closed" shown for an open tab. Every fix tuned the guess (latest #479, `SURE_MATCH` 70). The root:
the tab has **no owner when it opens**, and the owner is **inferred** later.

## Rules kept
- Safety unchanged: never Submit, never a password value, tests through the harness, never the owner's window. Universal: no site names or host lists in new code.
- Flow core touched (`extension/tabs.js`, `tab-identity.js`, `background.js`): read their "Invariants:" blocks; the open PR is the claim. Tier 2.
- A recorded case if page-acting code changes (must fail on main). Live proof: the PR's CI check (Pool-row line); no Mac live runs.
- Files ≤ 500 lines: `form-tab.js` is 206; the new picker is its own file.

## Open choices (my default in bold)
1. Mark syntax: **`#jobpilotto-fill=<id>`** (everything that tests `includes('#jobpilotto-fill')` keeps working) vs a query param (sites rewrite them).
2. Legacy tabs (no owner): **`scoreTab` stays, confident only, no new tab** vs drop guessing entirely (a pre-change tab then needs one re-open from the app).
